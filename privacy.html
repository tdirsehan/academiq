Privacy Information

This page describes the current public version of AcademIQ Tools and its linked applications.

Current website

The AcademIQ Tools landing page is a static GitHub Pages website. The landing page itself does not require an account, subscription, or payment and is not designed to collect personal information through a server-side form.

Linked tools

AcademIQ Tools links to separate public applications. Some tools may process text or files in the browser, use browser storage for local convenience features, or query third-party scholarly services such as OpenAlex. Users should avoid entering confidential, unpublished, personally identifying, or institutionally restricted information unless they have independently determined that doing so is appropriate.

Third-party services

External services, GitHub Pages, APIs, publisher websites, and any donation provider linked from the site may have their own privacy policies and data practices. AcademIQ Tools does not control those third-party policies.

Donations

AcademIQ does not collect payment-card or banking information on this website. If a user chooses to donate, payment information is handled by the external donation provider under that provider's own terms and privacy practices.

Contact

For project-related enquiries, use the developer profile linked from the main site.
