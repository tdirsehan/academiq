Privacy Information

This page describes the current public demonstration version of Academic AI Toolkit. It is not a substitute for a negotiated institutional data-processing agreement.

Current website

The Academic AI Toolkit landing page is a static GitHub Pages website. The landing page itself does not require an account or payment and is not designed to collect personal information through a server-side form.

Linked public tools

The toolkit links to four separate public demonstration applications. Some tools may process text in the browser, may use browser storage for local convenience features, or may query third-party scholarly services such as OpenAlex. Users should avoid entering confidential, unpublished, personally identifying, or institutionally restricted information unless they have independently determined that doing so is appropriate.

Third-party services

External services, GitHub Pages, APIs, or publisher websites linked from the tools may have their own privacy policies and data practices. Academic AI Toolkit does not control those third-party policies.

Institutional use

If an institution proceeds beyond a public demo, privacy, access, retention, authentication, support, and data-processing requirements should be defined as part of the pilot or licensing scope before deployment.

Contact

For institutional enquiries, use the developer profile linked from the main site.
